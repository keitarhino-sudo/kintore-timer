# 筋トレタイマー

不均等インターバル対応の筋トレ用タイマー（PWA）。種目ごとに秒数を自由設定でき、複数テンプレートを保存できる。
記録した内容は Obsidian に書き出せる。

公開URL: https://keitarhino-sudo.github.io/kintore-timer/

---

## 記録のルール：「完走したセット」だけを数える

押し間違い（腕のつもりで肩を押した等）で記録が汚れないように、**カウントダウンが0まで到達した種目だけ**を記録する。

| 操作 | 記録される？ |
|---|---|
| 最後まで走り切った種目 | ✅ される |
| ⏭ でスキップした種目 | ❌ されない |
| ⏮ で戻ってやり直す種目 | ❌ いったん取り消し（やり直した結果が記録される） |
| 準備カウントダウン中に ✕ で抜けた | ❌ セッションごと記録に残らない |
| 途中で ✕ 中断 | ⚠️ そこまでに**終えた種目だけ**が「途中終了」として残る |

種目が1つも完走してないセッションは、そもそもログに書き込まれない。
なので「押し間違えてすぐ戻る」は完全に無害。

記録は種目が1つ終わるたびに localStorage に保存されるので、途中でアプリが落ちても完走分は消えない。

## 部位

- テンプレートに「既定の部位」、種目ごとに「部位」を設定できる
- 種目の部位が空なら、テンプレートの既定を継承する
- どちらも空なら「未設定」として記録される
- ホーム画面のテンプレカードに部位タグが出るので、押し間違い自体も減らせる

## セット数の数え方：「1セッションで1部位＝1セット」

**1回のワークアウトの中で同じ部位の種目を何個やっても、その部位は 1セット** として数える。

```
肩の日（サイドレイズ→フロントレイズ→リアレイズ→ショルダープレス→腹筋）
→ 肩 4種目ぶんの秒数 / 1セット、腹 1種目ぶんの秒数 / 1セット ＝ 計2セット
```

種目ごとに1セットと数えると、肩トレ1回で「22セット」みたいな意味のない数字になるため。
秒数は今までどおり全種目の合計。種目レベルの内訳は記録画面のセッション行で見られる。

## Obsidian連携

Obsidian 標準の URI スキーム [`obsidian://new`](https://obsidian.md/help/Extending+Obsidian/Obsidian+URI) を使っている。
**追加プラグインは不要**（`append=true` で既存ノートの末尾に追記、ノートが無ければ新規作成）。

### 書き込み先は2つ

**1. 専用ログノート**（既定: `05 日記/筋トレログ.md`）— 1セッション1行を追記

```markdown
- 2026-09-11 21:31 腕・肩の日 ｜ 腕 1分30秒/2セット・肩 40秒/1セット ｜ 計 2分10秒/3セット
- 2026-09-10 22:31 胸・体幹の日（途中終了） ｜ 体幹 1分30秒/1セット・胸 1分0秒/1セット ｜ 計 2分30秒/2セット
```

**2. 日記ノート**（既定: `05 日記/{{YYYY}}/{{YYYY}}-{{MM}}/{{YYYY}}-{{MM}}-{{DD}}.md`）— その日の合計を1行

```markdown
- 筋トレ：腕 1分30秒(2セット) / 肩 40秒(1セット) ｜ 計 2分10秒・3セット
```

### 使い方

1回のURIで書けるのは1ファイルだけなので、**ログノートと日記はそれぞれ別のボタン**になっている。

- ワークアウト完了画面に「📝 ログノートに記録」「📔 日記に記録」の2つが出る。両方に入れたいなら両方押す（押すとObsidianに切り替わるので、戻ってきてもう一方を押す）
- 送信済みのボタンは「✓ 記録済み」表示に変わる
- 押し忘れても、ホームに「未記録が N 件あるで」と出るし、📊 の記録画面からいつでも送れる
- 記録画面では日付ごとに「ログノートへ / 日記へ / コピー」が選べる
- 「✓」表示のボタンをもう一度押すと、確認のうえ**再送**できる（Obsidian側に届いてなかったとき用）

### 設定（⚙ボタン）

| 項目 | 既定値 | 備考 |
|---|---|---|
| Vault名 | **空欄** | 空欄＝「最後に開いたvault」に書く。基本は空欄でええ |
| ログノートのパス | `05 日記/筋トレログ` | `{{YYYY}}` `{{MM}}` `{{DD}}` が使える |
| 日記ノートのパス | `05 日記/{{YYYY}}/{{YYYY}}-{{MM}}/{{YYYY}}-{{MM}}-{{DD}}` | 空欄にすると日記に書かない |
| 1日の切り替わり時刻 | 4時 | 深夜3時の筋トレは前日の記録になる |
| 書き込み後にノートを開くか | 開かない | `silent=true` |

## 既知の制約・注意点

- **書き込み成否は検知できない**。URIを開いた時点で「記録済」にしている。届いてなかったら「✓」ボタンをもう一度押して再送する。
- **Vault名が1文字でも違うと黙って失敗する**。だから既定は空欄（＝最後に開いたvault）。設定画面の「テスト送信」で確かめられる。
- **日記には末尾追記される**。テンプレの `- ランニング：` の並びには入らない。ピンポイント挿入したい場合は Advanced URI プラグイン（`searchregex`）が必要。
- **日記を先に作っておくほうが安全**。存在しない日付に送るとテンプレ無しの空ノートが作られる。
- **日記への送信は1日1回**が前提（その日の合計を書くため）。2回送ると2行になる（新しい行のほうが正しい合計）。
- **記録は端末の localStorage にある**。iOSでは長期間使わないと消えることがあるので、設定画面の「全記録をJSONで書き出し」でたまにバックアップする。
- 書き込んだ後、Obsidian の同期（remotely-save）が回るまで PC 側には現れない。

## 開発メモ

- 単一HTMLファイル（`index.html`）＋ `sw.js` / `manifest.json` / `icon.svg` のみ。ビルド不要。
- Service Worker は stale-while-revalidate。デプロイした更新は「次回起動時」に反映される。
  更新を即反映したいときは `sw.js` の `CACHE` のバージョンを上げる。
- localStorage のキー
  - `kintore-timer-templates-v1` … テンプレート
  - `kintore-timer-log-v1` … ワークアウト記録
  - `kintore-timer-settings-v1` … Obsidian連携の設定
